# Aviation Transcriber Pro ✈️

**Aviation Transcriber Pro** — это настольное приложение для автоматического распознавания и транскрибирования записей авиационного радиообмена. Программа использует нейросетевые модели семейства Whisper для точного перевода речи в текст и детектор голосовой активности (Silero VAD) для корректного разделения реплик пилотов и диспетчеров.

## 🌟 Основные возможности

* **Высокоточная транскрибация:** Распознавание сложной авиационной речи с сильным фоновым шумом.
* **Локальная обработка:** Все вычисления производятся локально на вашем оборудовании (CPU/GPU) без необходимости подключения к интернету.
* **Умное разделение диалогов:** Использование Silero VAD для нарезки аудиопотока по естественным паузам.
* **Встроенный аудиоплеер:** Возможность прослушивания аудиофайла прямо в приложении.
* **История расшифровок:** Сохранение всех результатов в локальную базу данных SQLite с возможностью удобного поиска и просмотра.

## 🛠 Стек технологий

* **Язык программирования:** Python 3.11
* **Графический интерфейс:** CustomTkinter (CTk)
* **Машинное обучение:** PyTorch (CUDA), Transformers (Hugging Face)
* **Обработка аудио:** FFmpeg, Pygame, Librosa
* **База данных:** SQLite

## ⚙️ Установка и настройка

### 1. Системные требования
Убедитесь, что в системе установлен **FFmpeg** и прописан в переменные среды, либо исполняемый файл `ffmpeg.exe` находится в директории проекта по пути `ffmpeg/bin/ffmpeg.exe`.

### 2. Установка библиотек
Для корректной работы нейросети с аппаратным ускорением (CUDA) необходимо установить библиотеки в строгой последовательности. 

Выполните следующие команды в вашем терминале (пути указаны для локальной среды):

**Установка PyTorch с поддержкой CUDA 12.1:**
```commandline
-m pip install "torch-2.5.1+cu121-cp311-cp311-win_amd64.whl" torchvision torchaudio --index-url [https://download.pytorch.org/whl/cu121](https://download.pytorch.org/whl/cu121)
